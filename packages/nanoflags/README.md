# nanoflags

The [NanoFlags](https://nanoflags.io) command line under its short name.

```sh
npx nanoflags init
npx nanoflags --help
```

This package contains no code of its own beyond a small launcher: it depends on one exact version of
[`@nanoflags/cli`](https://www.npmjs.com/package/@nanoflags/cli) and runs its `nanoflags` command. Both packages
share the same version number. Commands, options and documentation are those of `@nanoflags/cli`
(<https://nanoflags.io/docs>). Node 20 or newer.
