# NanoFlags Provider

The NanoFlags provider manages feature flags, their per-environment targeting (rules and percentage rollouts),
segments and publishing through the [NanoFlags Management API](https://nanoflags.io/docs/api-reference).
Every request runs as the person who created the token, with that person's current role, narrowed by the token's
scopes, and is recorded in the audit log.

## Authentication

Create a Management API token (`nf_api_…`) in the dashboard under **Settings → API tokens** (organization owners and
admins). Give it the scopes the resources you use need, and prefer a token scoped to one project:

| Resource / data source | Scopes |
| --- | --- |
| `nanoflags_flag`, `nanoflags_flag_environment`, data source `nanoflags_flag` | `flags:read`, `flags:write` |
| `nanoflags_segment` | `segments:read`, `segments:write` |
| `nanoflags_environment_publish` | `publish`, `flags:read` |
| `nanoflags_slack_destination` | `integrations:write` (admin role) |
| data source `nanoflags_sdk_keys` | `keys:read` (admin role) |
| data sources `nanoflags_project`, `nanoflags_environment`, `nanoflags_environments` | any valid token |

Pass the token through the `NANOFLAGS_API_TOKEN` environment variable rather than in configuration.

## Drafts and publishing

Flag and segment changes edit each environment's **draft**, exactly like the dashboard; SDKs only receive published
revisions. Publish with `nanoflags_environment_publish`, or through the dashboard's review flow in environments that
require approvals or scenario checks.

## What the API does not manage

Projects, environments and SDK keys are created in the dashboard; the provider reads them with data sources. Flags
cannot be deleted, only archived: destroying a `nanoflags_flag` archives it.

## Example Usage

```terraform
terraform {
  required_providers {
    nanoflags = {
      source  = "nanoflags/nanoflags"
      version = "~> 0.1"
    }
  }
}

# The token is read from NANOFLAGS_API_TOKEN when api_token is omitted (recommended).
provider "nanoflags" {
  # api_token = var.nanoflags_api_token
  # base_url  = "https://edge.nanoflags.io"
}
```

## Schema

### Optional

- `api_token` (String, Sensitive) Management API token (`nf_api_…`). Defaults to the `NANOFLAGS_API_TOKEN` environment variable. Scopes needed: `flags:read`/`flags:write` for flags and their environment configuration, `segments:read`/`segments:write` for segments, `publish` for `nanoflags_environment_publish`, `keys:read` for `nanoflags_sdk_keys`, `integrations:write` for `nanoflags_slack_destination`.
- `base_url` (String) NanoFlags edge URL. Defaults to the `NANOFLAGS_BASE_URL` environment variable, then `https://edge.nanoflags.io`. The Management API is served under `/api/v1`.
