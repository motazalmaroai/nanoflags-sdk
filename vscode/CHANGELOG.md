# Changelog

## 0.1.0 (2026-11-21)

First release.

- Sign in with a NanoFlags Management API token, stored in VS Code's secret storage.
- Flag key detection in JavaScript, TypeScript, Python, Go, Java, C#, PHP, Ruby, Kotlin, Swift and Dart (NanoFlags SDK
  getters and OpenFeature getters).
- Hover with the flag's name, type, per-environment status (published and draft) and a dashboard link.
- “Open in NanoFlags” CodeLens, flag key completion inside getter calls, problems for unknown and archived flags.
- Flags explorer per environment, copy flag key, refresh, project selection; cached data refreshes in the background.
